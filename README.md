# Social Media API Service (Backend) 🚀

This repository contains the scalable and robust backend infrastructure for a social media ecosystem. The project is developed under a **6-month professional 1-on-1 mentorship** from a Senior Software Engineer, focusing on industry-standard practices, clean architecture, and modern backend design.

> **Status:** Work in Progress (WIP) — Core architecture, database schemas, and TypeScript environment are fully established. Active development is focused on completing business logic and specialized API endpoints.

## 🛠️ Tech Stack
- **Runtime Environment:** Node.js
- **Programming Languages:** JavaScript & TypeScript
- **Database Server:** MongoDB Atlas (Cloud Database)
- **ODM (Object Data Modeling):** Mongoose

## 📌 Features & Architectural Decisions
- **JavaScript to TypeScript Migration:** Initially developed with JavaScript and progressively migrated to TypeScript to leverage strong typing, compile-time error catching, and scalable codebase architecture.
- **Cloud Database Integration:** Utilizes MongoDB Atlas for cloud-based, flexible document storage, maintaining optimized schemas via Mongoose.
- **RESTful Design:** Standardized HTTP methods and JSON payloads for clean data exchange.
